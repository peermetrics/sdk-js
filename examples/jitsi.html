🚀 Jitsi Meet SDK Integration

Full WebRTC monitoring: This example uses the Jitsi Meet SDK (not External API) for direct access to RTCPeerConnection objects.

• Direct access to WebRTC connections and stats
• Complete ICE connection monitoring
• Packet loss, jitter, and bitrate tracking
• Real-time network performance metrics
Label hint: Throughput can show multiple series per participant (audio/video and inbound/outbound). Transport peers may appear as ... (P2P) or ... (JVB/SFU).
Note: Room names must be lowercase and alphanumeric only
Note: config.js loads in <head> before lib-jitsi-meet. After updating this file, use a hard refresh (Ctrl+Shift+R) so the browser does not run an old cached page (old builds used BOSH as serviceUrl and show generic error hints).
Note: For production, use your own Jitsi deployment and its config.js.
Note: On meet.jit.si, CONFERENCE_FAILED: …membersOnly is common: the service expects meetings to be created in the official web client (often with sign-in), and some rooms are lobby- or members-only. Use a fresh random room name, open the same room once in a browser as moderator, or point this example at your own Jitsi server below.
