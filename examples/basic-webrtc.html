PeerMetrics SDK - Basic WebRTC

This page simulates two peers in one browser (two RTCPeerConnections, two getUserMedia streams). PeerMetrics monitors the local caller leg (pc1) and treats the other endpoint as a synthetic participant so the current user session has a real peer connection associated with it. The second leg exists only to complete the call in-process. For full two-party telemetry, use two browsers or devices.
