PeerMetrics SDK - Basic WebRTC

This page simulates two peers in one browser (two RTCPeerConnections, two getUserMedia streams). PeerMetrics only monitors one of them (the answerer, pc2) so the dashboard shows two participants: you and one synthetic remote peer. The other leg exists only to complete the call in-process. For full two-party telemetry, use two browsers or devices. If the peer row still looks empty, the API may not be storing stats for this loopback shape; check network responses for /stats and /connection.
